2. Understanding Memory Hierarchy

CPU Registers

Registers are small storage locations inside the processor. They temporarily hold operands, addresses, and intermediate results.

Cache Memory

Cache stores copies of data and instructions that may be needed again. A cache hit means the requested block is present. A cache miss means it is absent from the cache.

Main Memory (RAM)

RAM holds active programs and data. It is generally slower to access than cache and loses its contents when power is removed.

Secondary Storage

SSDs and HDDs retain files and applications even when the computer is turned off. They generally provide greater capacity than RAM but have higher access latency.

Locality of Reference

Temporal locality: recently accessed data may be accessed again soon.

Spatial locality: data near a recently accessed location may be accessed soon.

7. Formulas and Assumptions

Cache Hit Rate

Hit rate = (Number of hits ÷ Total accesses) × 100%

Cache Miss Rate

Miss rate = (Number of misses ÷ Total accesses) × 100%

Average Access Time

Average time = [(Hits × Hit time) + (Misses × Miss time)] ÷ Total accesses

Simulator Model

  • Memory block IDs range from 0 to 15.
  • The cache is fully associative: any block can occupy any cache slot.
  • LRU replacement removes the least recently used block when full.
  • Hit time is 5 ns and miss time is 85 ns in this educational model.
  • This model does not simulate byte addresses, cache lines, write policies, or multicore cache coherence.
